# 🔧 Bengkelku

**Bengkelku** adalah aplikasi layanan bengkel online yang menghubungkan **Customer, Montir, dan Admin** dalam satu platform.

Aplikasi ini dirancang untuk memudahkan pengguna mencari layanan bengkel, melakukan pemesanan, mendapatkan bantuan montir, serta memudahkan admin mengelola operasional bengkel.

---

## 🚗 Fitur Utama

### 👤 Customer
- Registrasi dan login akun
- Verifikasi OTP melalui nomor HP
- Melengkapi data diri dan alamat
- Melihat daftar layanan bengkel
- Melihat harga layanan
- Memilih layanan yang dibutuhkan
- Melakukan pemesanan montir
- Melihat lokasi secara realtime
- Melihat status pesanan
- Melihat informasi montir
- Riwayat servis
- Notifikasi pesanan

### 🔧 Montir
- Login akun montir
- Melihat pesanan masuk
- Menerima atau menolak pesanan
- Melihat lokasi customer
- Navigasi menuju lokasi customer
- Mengubah status pekerjaan
- Melaporkan pekerjaan selesai
- Melihat riwayat pekerjaan

### 🛠️ Admin
- Dashboard admin
- Mengelola customer
- Mengelola data montir
- Mengelola layanan bengkel
- Mengatur harga layanan
- Mengelola pesanan
- Memantau pekerjaan montir
- Melihat riwayat transaksi
- Mengelola data aplikasi

---

## 📍 Layanan

Bengkelku dapat digunakan untuk berbagai kebutuhan seperti:

- Servis kendaraan
- Ganti oli
- Tambal ban
- Ganti aki
- Perbaikan mesin
- Cek kendaraan
- Servis darurat
- Panggil montir ke lokasi

---

## 🎯 Tujuan

Bengkelku dibuat untuk memberikan solusi layanan bengkel yang:

- Cepat
- Mudah
- Transparan
- Praktis
- Terintegrasi
- Bisa digunakan kapan saja

Customer tidak perlu lagi bingung mencari bengkel atau montir ketika kendaraan bermasalah di jalan.

---
